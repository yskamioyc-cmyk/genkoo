# 要件定義書：原稿用紙対応デスクトップテキストエディタ v.1.0.0

## 1. 更新履歴
- **2026-05-25**: 初版作成

## 2. アプリケーションの概要
* **プロジェクトの目的**：小説や論文の執筆に特化し、日本語の縦書きおよび400字詰め原稿用紙のフォーマットで快適に執筆できるデスクトップアプリケーションを作成する。
* **ターゲット**：自分自身（または、縦書き・原稿用紙スタイルでの執筆環境を求める書き手）
* **動作環境**：PCローカル環境（windows/Mac/Linux）、完全オフライン動作。

## 3. 機能要件
### 3-1. 執筆・入力機能
- [ ] 縦書き表示モード\
・文字が右から左、上から下へと流れる日本語標準の縦書きに対応する。
- [ ] 400字詰め原稿用紙フォーマット\
・20文字×20行のマス目（グリッド）を表示する。\
・入力した文字が1マスに1文字ずつ綺麗に収まる。
- [ ] リアルタイム文字数カウント\
・現在の総文字数などを画面の端に表示する。
- [ ] 原稿用紙枚数換算\
・総文字数とは別に、「原稿用紙換算で何枚分か」を表示する。
- [ ] 禁則処理\
・行頭に「、」や「。」、閉じカッコが来ないように自動で調整する。

### 3-2. ファイル入出力管理
- [ ] 新規作成・開く・保存\
・PC内のファイル（`.txt`または`.md`）を読み込んで編集できる。\
・編集した内容を上書き保存・別名保存できる。
- [ ] 完全オフライン動作\
・起動やファイルの保存にインターネット接続を一切必要としない。
- [ ] 自動保存（オートセーブ）\
・数分ごと、あるいは1文字入力するごとにバックグラウンドで自動保存され、クラッシュ時のデータ消失を防ぐ。

### 3-3. UI/UX
- [ ] レスポンシブな原稿用紙表示\
・ウィンドウのサイズを変更しても、原稿用紙のレイアウト（20×20）が崩れない。
- [ ] フォント・文字サイズ変更\
・明朝体やゴシック体など、執筆しやすいフォントに切り替えられる。
- [ ] ダークモード対応\
・夜間の執筆でも目が疲れないよう、黒基調の画面（緑のマス目に白い文字など）に切り替えられる。

### 3-4. 出力機能
- [ ] テキスト書き出し\
・装飾のない純粋なプレーンテキスト（`.txt`）としてエクスポートできる。
- [ ] 印刷・PDF出力\
・原稿用紙のマス目ごと、綺麗にA4サイズなどで印刷・PDF化できる。

## 4. 非機能要件
* **起動速度**：テキストエディタとして使い手にストレスを感じさせないよう、3秒以内に素早く起動できること。
* **データ保存性**：アプリが強制終了しても、直前までのテキストデータが極力保護されていること。
